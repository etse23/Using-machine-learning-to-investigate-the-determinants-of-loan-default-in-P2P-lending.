# Using-machine-learning-to-investigate-the-determinants-of-loan-default-in-P2P-lending.
This study applies four supervised machine learning models (Fine Decision Tree, Efficient Logistic Regression, Linear Support Vector Machine (SVM), and Boosted Trees Ensemble) to predict loan approval outcomes in peer-to-peer (P2P) lending using a 614-record Kaggle dataset with 13 borrower and loan features.
